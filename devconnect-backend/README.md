# DevConnect Backend

Backend API for **DevConnect**, a developer community platform where users can connect, share posts, follow each other, and receive notifications.

---

## 🚀 Tech Stack
- Node.js
- Express.js
- MongoDB (Mongoose)
- JWT Authentication
- bcrypt

---

## ✨ Features

### Authentication
- User registration & login
- Password hashing
- JWT-based authentication
- Protected routes

### User System
- Get & update profile
- Search users by name
- Follow / unfollow users
- Followers & following lists

### Post System
- Create posts
- Fetch feed
- Like / unlike posts
- Delete own posts
- Comment on posts

### Notifications
- Follow notifications
- Fetch user notifications
